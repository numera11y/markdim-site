# Product

<!-- impeccable:product-schema 1 -->

## Platform

adaptive

## Stack

C# with Avalonia UI on .NET 10 for the desktop application. The promotional website is a separate Astro static site using Tailwind CSS 4 and Phosphor icons.

## Users

People who create, receive, read, or maintain Markdown files on their computer, including files produced by coding agents such as OpenCode. They want a comfortable way to edit the source, inspect its rendered form, organize several files, and share the result.

## Product Purpose

markdim is a free desktop application for opening, creating, editing, organizing, reading, and exporting local Markdown documents. Success means the user can move from an existing `.md` file to a revised document or PDF without moving the source into a web service.

## Positioning

A local desktop workspace that puts the Markdown source, live rendered preview, file library, and PDF export together. markdim is open source under the MIT license and the project targets Windows, macOS, and Linux. Public beta packages are currently available for Windows and Linux.

## Operating Context

Users open a `.md` or `.markdown` file, or a folder of documents; search and move between tabs; edit source while following the preview; adjust the workspace and reading settings; and export a PDF. Agent-produced Markdown is one input among many, not the only use case.

## Capabilities and Constraints

Confirmed capabilities: local files and folders, library search and outline, reorderable tabs, editable Markdown source, live preview, CommonMark and advanced Markdig extensions, code-block highlighting, find/replace, configurable and persistent panels, light/dark themes, source-text zoom with Ctrl+mouse wheel, and PDF export. The application adds no account, cloud synchronization, or telemetry. The public beta is not currently distributed for macOS; do not imply a macOS download is available.

## Product Principles

- Keep Markdown files local and easy to open.
- Keep source and rendered reading view together.
- Make the workspace adaptable to the current document and reader.
- Make creating and exporting a finished document straightforward.
- Communicate current platform availability accurately.
